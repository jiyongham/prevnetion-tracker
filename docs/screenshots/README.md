# 스크린샷 가이드

이 저장소는 **public**이다. 화면에는 실제 시스템명·호스트명·IP·담당자 이름이 그대로 뜨므로,
**마스킹하지 않은 캡처를 커밋하면 히스토리에서 지우기 어렵다.** 올리기 전에 아래를 확인할 것.

## 마스킹 체크리스트

캡처 안에 다음이 남아 있지 않은지 확인한다.

- [ ] **시스템명 / CI명** — `[관계사,인프라] 서비스명` 형태로 관계사·서비스가 드러남
- [ ] **호스트명** — 명명 규칙에서 용도·환경이 유추됨
- [ ] **IP 주소** — 사설 대역이라도 대역 구성이 드러남
- [ ] **담당자 이름** — 표의 담당자 열, 리마인드 본문의 수신자
- [ ] **운영팀명** — 조직도가 드러남
- [ ] **JIRA 티켓 키 / Insight Key** — 프로젝트 키와 번호대
- [ ] **브라우저 주소창** — 사내 호스트가 찍힘. 주소창을 빼고 캡처하거나 잘라낼 것
- [ ] **탭 제목 / 북마크바** — 다른 사내 시스템 이름이 노출되기 쉬움

## 권장 방법

가장 안전한 건 **더미 데이터로 띄운 화면을 캡처**하는 것이다. 엑셀의 해당 열만
`시스템 A`, `host-a01`, `10.0.0.1`, `홍길동-운영1팀` 같은 값으로 바꿔 로컬에서 띄우면
마스킹 누락 위험이 없고 화면도 깔끔하게 나온다.

이미지 편집으로 가리는 경우 **블러는 피하고 단색 박스로 덮을 것.** 약한 블러는
복원될 수 있다. 픽셀레이트도 마찬가지다.

## 파일 이름

README가 참조하는 이름이다. 그대로 쓰면 주석만 풀어도 바로 붙는다.

| 파일 | 화면 |
|---|---|
| `01-dashboard.png` | 포털 홈 또는 도메인 대시보드 전체 |
| `02-list.png` | 대상 목록 (인라인 편집·필터가 보이게) |
| `03-owner-check.png` | 담당자 확인 |
| `04-remind.png` | 리마인드 미리보기 |

`01`은 README 최상단에 들어가는 대표 이미지라 가장 공들일 값어치가 있다.

## 크기

- 가로 **1600px 내외**, 파일당 **500KB 이하** 권장 (`png` → 필요하면 `pngquant` 등으로 압축)
- 세로로 긴 목록은 전체를 다 담지 말고 **상단 20~30행**만 잘라내는 편이 읽기 좋다
