화면 이용 순서

  1. 왼쪽 메뉴의 진척 현황에서 반기와 수행방식을 선택합니다.
  2. 팀·검색어와 상태/조치 필터로 처리할 대상을 찾습니다. 필터 기억하기를 켜면 현재 브라우저에 검색 조건이 저장됩니다.
  3. 일정·증적·비고를 입력한 뒤 행의 저장 버튼 또는 현재 목록 일괄 저장을 누릅니다.
  4. 상·하반기 비교에서 반기별 방식·상태·증적을 확인하고, 변경 이력에서 수정 내역을 검색합니다.

하반기 수행방식

하반기는 상반기 결과를 기준으로 수행방식을 계산합니다. 대상 수는 현재 데이터에 따라 달라지며 고정 숫자가 아닙니다.

완료와 증적 확인

완료율은 대상 여부가 O인 항목을 기준으로 계산합니다. 엑셀·웹의 완료 표기, 관리자 제외 인정일, 해당 반기의 JIRA 근거를 순서대로 판정합니다. 일정이 지났다는 이유만으로 완료 처리하지 않습니다.

JIRA 근거는 실전환을 우선하며 변경계획완료일을 사용합니다. 무중단은 제목의 ‘무중단’과 이슈 유형 ‘서비스요청관리’를 확인하고 생성일을 사용합니다. 날짜는 해당 반기 안이면서 기준일 이전이어야 합니다.

증적 티켓의 상태 경고와 완료 판정은 별도로 표시됩니다. 증적을 입력했다는 사실만으로 완료가 보장되는 것은 아닙니다.

Teams 리마인드와 변경 이력

리마인드는 실전환/무중단 및 완전 미기입/대략적 일정/작업 {{ pre_work_days }}일 이내로 나누어 초안을 확인합니다. 발송 전 대상과 수신자를 확인하세요.

사전 안내는 일정 입력자를 기준으로 하되, 관리자가 대신 입력했거나 엑셀 원본 일정인 경우 서비스별 대표 담당자를 사용합니다.

관리자 수정은 일반 변경자 표시에서 가리지만 감사 이력은 보존됩니다. 메뉴의 관리자 표시 여부는 편의 기능이며 실제 권한 검사와는 별개입니다.
